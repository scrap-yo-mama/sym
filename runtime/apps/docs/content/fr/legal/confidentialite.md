# Confidentialité

> Brouillon, à valider par un avocat avant la mise en ligne de ce site. Ce texte n'est pas un avis juridique.

En cas de divergence, la version française fait foi. Le texte anglais est la [page de confidentialité en anglais](/legal/privacy){.vp-raw}.

## Qui est responsable

L'éditeur de ce site est nommé dans les [mentions légales](/fr/legal/mentions-legales){.vp-raw}.

## Ce que cette page collecte

Rien. Cette page ne dépose aucun cookie, n'exécute aucune analyse d'audience, n'a aucun formulaire et ne te demande ni compte ni adresse e-mail. Elle ne charge rien chez un tiers : les polices, les scripts et les images viennent de la même adresse que la page.

## Ce que ton navigateur garde

Si tu choisis un thème clair ou sombre, ton navigateur garde ce choix dans son stockage local. Cela n'arrive qu'après que tu as fait ce choix, n'utilise aucun identifiant et n'est envoyé nulle part. Ta langue n'est pas enregistrée : tu la choisis avec le lien de langue. Les pages de documentation du même site ont leur propre sélecteur de thème : il garde ta préférence dans ce même stockage local dès leur ouverture, avec la valeur « auto » (le thème de ton système) tant que tu n'as rien choisi, sans identifiant et sans rien envoyer. Reste à confirmer par un avocat si ce stockage relève de l'article 5, paragraphe 3, de la directive ePrivacy.

## Ce que l'hébergeur enregistre

Ce site est servi par GitHub Pages. Comme tout hébergeur web, GitHub peut enregistrer des données techniques quand ton navigateur demande une page, comme ton adresse IP, l'heure de la requête et le user agent de ton navigateur. Nous ne recevons pas ces journaux. La [déclaration de confidentialité](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) de GitHub décrit ce qu'il en fait.

## Les liens vers d'autres sites

Les liens vers GitHub, Render ou Railway envoient une requête à ces services seulement quand tu cliques dessus. Leurs propres politiques de confidentialité s'appliquent ensuite.

## Le logiciel

SYM, le logiciel, ne nous envoie rien : ni télémétrie ni vérification de version. Voir la [page Télémétrie](/explications/telemetrie){.vp-raw}.

## Tes droits

Le RGPD te donne des droits d'accès, de rectification et d'effacement sur les données personnelles qu'un responsable de traitement détient sur toi. Ce site n'en détient aucune. Pour toute question, écris à l'adresse indiquée dans les [mentions légales](/fr/legal/mentions-legales){.vp-raw}.
