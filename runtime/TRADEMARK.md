# Politique de marque

> **Brouillon, à valider par un avocat avant toute publication.** Ce texte n'est pas un avis juridique. La **disponibilité du nom « Scrapyomama » n'a pas été vérifiée** (INPI, EUIPO, USPTO), et aucun dépôt de marque n'a été fait. Tant que ce n'est pas fait, ce document exprime une intention, pas un droit acquis.

## Pourquoi un document séparé

Les licences du dépôt (AGPL-3.0-only, MIT) donnent le droit de copier, modifier et redistribuer le **code**. Elles ne donnent aucun droit sur le **nom** ni sur le **logo** : l'AGPL-3.0 (article 7) permet expressément de refuser d'accorder des droits de marque. Quiconque publie un fork peut réutiliser le code, pas se présenter comme le projet d'origine.

## Ce qui est libre

- Désigner le produit par son nom pour dire ce qu'il est : articles, tutoriels, comparaisons, compatibilité (« fonctionne avec Scrapyomama Runtime »).
- Dire qu'un service ou un outil est « propulsé par Scrapyomama Runtime » (« Powered by »), à condition de ne pas laisser croire à un partenariat ou à un soutien du projet.
- Redistribuer une version **non modifiée** sous son nom.

## Ce qui demande un accord écrit préalable

- Distribuer une version **modifiée** sous le nom « Scrapyomama » ou un nom qui s'en rapproche : renommez votre fork.
- Proposer un service commercial hébergé ou une offre payante sous le nom du produit, ou sous un nom susceptible d'être confondu avec lui.
- Utiliser le logo, le nom ou l'identité visuelle d'une façon qui suggère une publication officielle.
- Publier sous ce nom sur une place de marché (extensions de navigateur, registres de paquets, images de conteneur).

## Ce qui reste interdit

- Présenter un fork, une version modifiée ou un service tiers comme officiel.
- Associer le nom du projet à des fonctions que le projet exclut par conception ([Hors périmètre](docs/hors-perimetre.md)).

1. Disponibilité et dépôt du nom et du logo (pays, classes, coût).
2. Règle applicable à l'offre hébergée d'un tiers.
3. Conséquence, pour la marque, d'un éventuel changement de titulaire du dépôt.
